# Functional Requirements

## Driver Module

- Register a new account
- Login using email and password
- View available parking slots
- Book a parking slot
- Cancel a booking
- View booking history

## Attendant Module

- Login to the system
- Verify user bookings
- Perform vehicle check-in
- Perform vehicle check-out
- Update parking slot status

## Admin Module

- Add parking lots
- Add parking slots
- Edit parking lot details
- Edit parking slot details
- Remove inactive slots
- View booking reports
- View parking occupancy analytics

## System Requirements

- Authenticate users using JWT
- Prevent double booking of slots
- Store booking records securely
- Track real-time slot availability
- Maintain booking and parking history
